# Fish n Wire is an e-commerce platform built using Django and React.

Data is coordinated between Redux / Axios / Thunk paired with Django-Rest-Framework. It has many of the features you would want in an e-commerce store. There is custom checkout flow - wherein orders can be made but payment is not required until items are ready to ship. 

Styling is achieved through TailwindCSS

## To fork this app

- Clone repo
- From backend, pip install and configure environment variables in an .env file
- From frontend, npm install and configure environment variables
